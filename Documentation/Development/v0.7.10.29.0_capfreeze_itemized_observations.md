# v0.7.10.29.0 - Cap Freeze itemized evidence observations

This pass adds `Knowledge/Contracts/capfreeze_observations.py`, a bounded parser for operator-supplied **plain-text** team-page snapshots. It performs no automated HTTP requests and makes no claim of permission to scrape or bulk reuse Cap Freeze content. Publisher data remains independent, unverified observations, not canonical cap charges.

Observed source: https://capfreeze.com/teams/toronto-maple-leafs.html (retrieved for research 2026-10-17; page identifies its data as of 2026-10-08). Sections: forwards, defense, goalies, dead cap, unsigned RFAs, non-roster/minors. Cap Freeze explicitly labels figures estimates; the page's LTIR pool is not sufficient to derive verified CBA relief.

Use `parse_capfreeze_team_text(team_id, text, source_url=..., retrieved_at=...)` with supplied plain-text content. Its results are source observations only. It checks identity, season, source date, total/space/ceiling consistency and keeps minors separate. It emits warnings if itemized active/dead-cap charges do not match published totals. The parser does not auto-promote observations into `CapCharge` or set completeness flags.

Offline fixture regression: `Tests/validate_capfreeze_observations_0710290.py`.
