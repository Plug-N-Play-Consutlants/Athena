# AthenaEngine v0.7.10.59.1 — Inquiry Integrity & Editorial Refinement

## Install

Scoped **13-file** overlay for v0.7.10.59.0. Extract archive with `AthenaEngine/` under `F:\Development\` (or copy the contents of the archive's `AthenaEngine/` folder over the existing repository). Then **Reload Build → Verify → Sync League → Scout**. This overlay does **not** replace the entire source repository.

## Root cause and fixes

- A short registered public player alias (`ove`) was treated as a substring of `improve`, promoting an unrelated roster question to an Alex Ovechkin profile. Entity matching now requires whole lexical name/alias phrases; 1–3-character nicknames only match entire normalized queries. Long descriptive questions do not receive short-name edit-distance guesses. Explicit player names, including Alex Ovechkin/Ovi, continue to resolve.
- The legacy fantasy roster planner only recognized generic `my roster` phrases. A new Athena-owned subject detector recognizes **unique, whole-phrase team names from currently loaded canonical team profiles or the player master** and a genuine roster-evaluation objective. This precedes unrelated player routing in either Public or Fantasy presentation mode; the execution bridge passes canonical fantasy context when Public explicitly asks about a named fantasy team.
- The specialist now answers for the **requested team**, not an unrelated league ranking, and distinguishes current inventory, model-derived value signals, verified production, historical active-slot eligibility and unsupported trade recommendations. Without adequate evidence, it presents a relevant bounded diagnostic and specifies the next required comparison; it does not fabricate a player recommendation.
- Scout's role selection no longer mistakes every roster *diagnostic* for an *auditor* assignment; specialist voice remains analyst. Explicit scoring reconciliation and runtime diagnostics remain audit-first.
- Missing official NHL statistics no longer erase a player's curated historical identity/legacy. Historical seeds are labelled as curated context, never passed off as fresh official statistics or a verified current team; no manufactured numeric career totals or honours are introduced.
- The weekly journalism pathway connects the significance of a standings climb with the actual highest period scorer, groups rank declines into connected prose, links relevant trades to the featured club **without claiming causation**, reduces mechanical repeated lines, and preserves clean attribution boundaries between NHL production and fantasy-credit evidence.
