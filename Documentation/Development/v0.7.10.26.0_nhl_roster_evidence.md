# v0.7.10.26.0 NHL roster evidence reconciliation

Adds a bounded, real NHL-host roster acquisition route and an identity-level reconciliation of itemized SPC evidence against the roster. This does not acquire NHL contracts, AAVs, retained salary, or LTIR; it does not certify cap ledger completeness. The official NHL roster endpoint is used as a roster source only. Its endpoint is community documented and deployment usage must respect upstream conditions. PuckPedia offers private data APIs by inquiry, not a documented unrestricted public cap API. Integration with a licensed contract source remains an explicit blocker to real complete cap calculation.
