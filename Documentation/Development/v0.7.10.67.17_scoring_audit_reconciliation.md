# v0.7.10.67.17 — Historical Scoring Audit Reconciliation

## Objective
Connect the audited NHL-v-Fantrax period results to Studio evidence diagnostics. Previously the refresh wrote `PeriodScoringAudit/<league>/<season>/period_NNN.json`, but the diagnostic read only the older `analyze_player_attribution` result. Studio therefore showed `unverified_join` even after an acquisition yielded a complete committed numeric audit.

## Changes
- Read committed `athena.period_attribution.v1` audit for the exact league, season, period, team coverage and source eligibility metadata; reject stale, wrong-season, ambiguous or malformed records.
- Expose per-period numeric agreement, absolute score deltas, unresolved Fantrax-to-NHL identity crosswalk count, crosswalk-resolved ACTIVE players without NHL game rows, and missing official scoring totals separately.
- Keep credited Fantrax scoring unverified. A historical ACTIVE snapshot and an exact NHL total still do not establish game-effective eligibility or individual credited points.
- Reuse existing Studio **Refresh & Reconcile Evidence** button and its command summary; no extra Studio actions.
- If no valid committed audit exists, preserve the legacy report path and `unverified_join` status.

## Boundaries
No new live Fantrax game-effective lineup feed, transaction identity crosswalk, or independently verified credited player scoring. Do not infer absence from no NHL game rows; they can reflect games missed, reserve deployments, or acquisition/identity gaps. No changes to upstream NHL acquisition/pagination.

## Acceptance
Run **Refresh & Reconcile Evidence** for periods 6–8 in Studio. Check that the refreshed reports expose audited team counts and point differences rather than generic `unverified_join` where committed audits are valid. Submit command output and diagnostics ZIP when unresolved identities or scoring differences remain.
