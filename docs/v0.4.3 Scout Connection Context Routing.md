# v0.4.3 — Scout Connection + Context Routing

## Purpose

Scout is now the local entry point for connecting a Fantrax league and running Athena's canonical fantasy-league analysis pipeline.

This release keeps Scout intentionally simple while adding the missing connection layer and context routing foundation.

## Added

- Connect Fantrax panel in Scout.
- Fantrax League ID input.
- Fantrax auth cookie / secret input.
- Test Connection action.
- Local saving of workspace details to `Configuration/workspace.json`.
- Local saving of Fantrax auth cookie to `Configuration/secrets.local.json`.
- Automatic context inference from `Raw/league_info.json` after connection.
- Fantasy League / Public Sports mode switch.
- Analyze League now runs the canonical Athena pipeline before rendering results.

## Context Inference

Scout now infers the following from Fantrax league data where available:

- league name
- sport
- season
- team count
- start date
- end date
- scoring style

The user should not need to manually enter sport or season context.

## Analyze League Pipeline

Analyze League runs:

1. `Providers/Fantrax/fetch/fetch_all.py`
2. `Providers/Fantrax/build/player_pool_master.py`
3. `Providers/Fantrax/build/player_master.py`
4. `Providers/Fantrax/build/transaction_master.py`
5. `Knowledge/transaction_history.py`
6. `Intelligence/manager_behavior.py`
7. `Intelligence/league_market.py`
8. `Knowledge/knowledge_readiness.py`

## Public Sports Mode

Public Sports mode is now routed separately, but is intentionally limited in this release. It does not yet include authoritative NHL/NHLPA/CBA reasoning. That is reserved for the next public-context foundation sprint.

## Known Limitations

- Fantrax finance page is still not fetched.
- NHL/NHLPA/CBA public context is not yet implemented.
- Fantrax auth still depends on a browser cookie in the local alpha.
- Scout answers remain deterministic templates, not freeform AI responses.
