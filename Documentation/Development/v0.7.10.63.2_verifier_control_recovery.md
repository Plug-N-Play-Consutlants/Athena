# AthenaEngine Studio — targeted Verify Build recovery

**Compatibility:** existing `v0.7.10.63.2` repository after the Studio recovery rollback.

**Scope:** Changes only `Tools/athena_studio.py` and adds a standalone verifier regression test. No modifications to `Core/version.py`, Scout launcher, server, intelligence modules, journals or provider data.

## Corrections

- `Verify Build` uses a dedicated bounded subprocess runner instead of the legacy `_run_command` path that reads stdout until EOF with no timeout.
- The active validation, its index and log path are displayed immediately. Progress emits every 10 seconds while a test is running.
- Each test writes output directly to its timestamped `Logs/athena_studio_commands` file as it runs. Large output is not accumulated in memory.
- Each registered test has a **150-second** default timeout; timeout marks the check failed and aborts the remaining verification sequence. Passing checks are never assumed when a validation is missing, stuck, or cancelled.
- Developer Mode contains `Cancel Verification`, which terminates only the active validation's subprocess tree. Closing Studio requests cancellation and waits for verification cleanup before closing.
- A concurrent `Verify Build` invocation is rejected. UI updates from this dedicated path are queued for Tk's main thread.
- Existing generic Studio commands, launch/reload logic, stop helper, runtime identity handling and data are unchanged.

## Testing

`python -m unittest Tests.test_studio_bounded_verifier_0710633 -v`

Five focused tests cover success, nonzero exit, forced timeout, live cancellation, and pre-cancellation. Linux container tests cannot establish Windows/Tk live acceptance; Windows needs one bounded live verification run.

## Installation

Unzip overlay into `F:\Development\AthenaEngine`, keeping paths, then **close and reopen Athena Studio**. In Developer Mode select Verify Build. You can monitor current check and log path or cancel it. A test exceeding 150 seconds will be identified as TIMEOUT, not silently skipped.

**Note:** The targeted overlay intentionally does not increment the product version. It is a verifier-control recovery patch for the already installed v0.7.10.63.2 baseline.
