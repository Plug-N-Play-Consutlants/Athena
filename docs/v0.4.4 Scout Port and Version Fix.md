# v0.4.4 — Scout Port and Version Fix

## Purpose

Ensures Scout visibly launches the current app version and avoids stale local server collisions.

## Changes

- Added visible Scout Alpha version badge.
- Added `/api/version` and `/api/health`.
- Updated `Scout/run_scout.py` to detect occupied local ports.
- If `localhost:8765` is already in use, Scout automatically launches on the next available port.
- Removed `SystemExit` launcher noise in Spyder.
- Added cache-busting browser launch URL.

## Validation

Use the browser page version badge and `/api/version` to confirm the active server.
