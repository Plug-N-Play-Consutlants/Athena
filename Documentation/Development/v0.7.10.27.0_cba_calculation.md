# v0.7.10.27.0 - Bounded CBA contract-charge calculations

Introduces source-evidenced, season-effective arithmetic for three verified obligation classes: active-roster SPC annual cap AAV, retained-salary share of original AAV, and buried contract charge using an externally verified season-specific exemption. Integrates optional CBA calculation into the existing contract obligation acquisition adapter; its previous API remains valid.

**Do not mistake this for operational NHL cap accounting.** Rule thresholds are caller-supplied and must be traced to authoritative, effective-dated CBA evidence. Current code does not implement full daily accounting, LTIR relief, bonus mechanics, buyouts, historical transition rules, provider contract coverage, or Scout inquiry integration. No live contract provider is configured. This build's fixture tests establish arithmetic and bounded ingestion only, not actual league-wide salary-cap correctness.

**Next integration gate:** Secure an authorized real itemized NHL contract/cap-obligation source; bind canonical rule evidence and effective thresholds; build complete, independently reconciled team calculations and test real Toronto plus another team before calling the feature operational.
