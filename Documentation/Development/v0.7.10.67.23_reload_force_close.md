# v0.7.10.67.23 — Reload Build force-closes Scout

`Reload Build` is a **stop-only** maintenance action. It uses the existing owned-process stop helper, verifies Scout ports are clear, purges Python caches, and leaves Scout stopped. It neither launches Scout nor opens the browser. `Launch Scout` remains an explicit separate button. `Restart Scout` remains an explicitly requested restart method, distinct from `Reload Build`.

If stopping Scout fails or a Scout listener remains, Reload Build stops before cache removal and reports failure. No process is launched. `Relaunch Studio` also stops Scout as implemented in v67.21.

Regression: `Tests/test_studio_reload_stop_only_07106723.py` exercises successful shutdown and both stop failure conditions. Windows acceptance must verify that the old Scout PID disappears and no new PID is created by Reload Build alone.
