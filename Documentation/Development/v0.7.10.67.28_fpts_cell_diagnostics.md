# v0.7.10.67.28 — Fantrax FPts Cell Decoding Diagnostics

The Studio Fantrax Diagnostics entry remains unchanged. This overlay adds bounded,
allowlisted structural analysis of the player-statistics `fpts` cells to the
existing read-only period probe. Numeric values may be nested in presentation
metadata; the decoder accepts only unambiguous numeric representations, rejects
markup/non-numeric strings and conflicting nested numeric fields, and never emits
player identities or raw values in the diagnostic. An anonymized hash of sorted
FPts values may demonstrate a different provider response, **not** period
identity or fantasy scoring credit. The selected and comparison requests report
cell structure and decoded value counts. No player-ledger writes.
