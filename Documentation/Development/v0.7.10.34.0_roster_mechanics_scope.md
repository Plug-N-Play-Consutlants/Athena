# v0.7.10.34.0 — Bounded roster move assessment

Adds a verified-input annualized cap delta for assignment and recall, explicitly
separating two-way salary rates, waiver eligibility, roster legality and NHL cap AAV.
Scenarios can be attached to the existing contract-evidence cap inquiry and
appear in its Scout-ready answer. This is **not** wired into the normal Scout
conversation dispatcher; it is an incremental integration at the cap-inquiry API.

## Important limitations / milestone status

The planned operational cap milestone is **NOT MET**. No authorized complete live
itemized contract feed has been connected. The engine does not calculate daily
accrual, LTIR, performance bonuses, buyouts or full team roster compliance.
Scenario eligibility flags are supplied and must be independently verified;
they are not computed from NHL waiver or roster rules. The tests are fixtures.

Do not mark the v0.7.10.34.0 real-world Milestone Intelligence Check PASS
based on this build's Studio Verify Build. Run the normal Public Scout prompts,
