# v0.7.10.36.0 — GM preference-aware scenario comparison

This increment introduces an opt-in `gm_scenario` to the existing evidence-to-cap inquiry executor. It preserves supplied player evidence when executive preferences change, treats protected players as hard exclusions, and requires provenance for every weighted comparable measure. Missing metrics block ranking, rather than being silently treated as zero. Outputs disclose advantages, costs, unknowns and feasibility limits.

**Scope limits:** This is not an autonomous player-market acquisition, a calibrated NHL projection model, an actual trade offer, an end-to-end normal Scout dispatcher integration, or daily cap/CBA clearance. The comparative numbers are provided by callers and must be evidence-grounded; fixtures are synthetic. Studio Verify Build and real-world Scout milestone checks remain necessary.
