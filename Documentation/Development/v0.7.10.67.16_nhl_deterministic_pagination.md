# v0.7.10.67.16 — Deterministic NHL REST game-level pagination

## Evidence

Sanitized v67.15 traces returned exactly 100 records per page while offsets advanced from 0 to 100 and onward. All periods eventually failed on overlapping `(playerId,gameId)` keys. Existing requests lacked explicit ordering; on an unordered endpoint, offset pagination is not stable.

## Change

All `skater/summary` game-level pagination requests now send a deterministic JSON `sort` by `gameId` ascending, then `playerId` ascending. The same ordering is applied to the initial request and all subsequent pages. Existing fail-closed duplicate, count, and schema checks remain. No missing evidence is manufactured and no fantasy credit is inferred.
