# AthenaEngine v0.7.10.65.0 — Phase 2: Verified Editorial Briefing

## Purpose
Restore meaningful league-wide standings detail and cross-period context in the *active* Scout journalist publishing pathway, while preserving Phase 1's single publication boundary and without modifying player scoring, NHL/Fantrax data, launchers, or profile routes.

## Canonical handoff
`Athena.Investigation.period_execution` calls `build_editorial_briefing` after `research_period` and standings archive continuity resolution. It attaches the version-neutral `editorial_briefing` extension to the existing `athena.league_period_research.v2` payload. `Scout.conversation.journalist_composition` presents the verified briefing, falling back to legacy finding-based prose only where the structured comparison is missing/incomplete.

### New briefing contract
- `status=verified` only for `comparison.status=compared`, allowed `source=canonical_period_standings` (or absent for backward compatibility), complete standings rows, unique team keys, and numeric cumulative/period totals and rank changes.
- `leaders`: all ties at the top-three weekly scoring boundary.
- `climbers`, `fallers`: **all** verified movers rather than hardcoded two-per-direction limits.
- `unchanged`, `front_runners`, `gaps_to_first`: derived from verified cumulative standings, never projected or inferred from NHL individual production.
- If evidence is incomplete, `status=unavailable`, and Scout uses its previous safe presentation path.

### Cross-period continuity
Three validated same-season snapshots now identify both uninterrupted movement and reversals. A reversal is not presented as an uninterrupted streak. Missing snapshots never create a multiweek conclusion. Long-standing streak wording remains supported.

## Boundaries deliberately unchanged
- `Core/version.py` bumped from v0.7.10.64.0 to v0.7.10.65.0.
- No Studio/Scout startup or listener modifications.
- No changes to player identities, period-scoring arithmetic, waiver processing, contractual rules or live provider adapters.
- No fictional motivation, fantasy-player point credit, transactions or rivalries.
- The publication gate from Phase 1 remains the sole journalist release boundary.
- Editorial *voice* and player-level causal attribution are not considered complete; this release advances verifiable narrative coverage, not full persona intelligence.

## Acceptance
Regression tests cover all verified movements, retained score coverage, verified cumulative standings context, fallback behaviour, absence of scoring overclaims, no input mutation, and reversal vs streak. Confirm Studio and Scout live launch on Windows and replay authentic Weeks 5–7 before accepting the next phase.
