# v0.7.10.30.0 — Independent Contract Verification Bridge

Source-first extension of the offline Cap Freeze observation importer. This pass
matches publisher player observations against independent NHL roster IDs and
separately supplied, provenance-bearing verified contract records. A name match
alone is insufficient to establish contract or roster status; identity collisions,
missing independent evidence, non-effective contracts, and mismatched AAVs are
reported or rejected. Only corroborated active SPC obligations are converted into
canonical partial-ledger charges through the existing ingestion pipeline.

No paid service, unauthorized crawling, or external API endpoint is introduced.
The input contract records must already have been independently verified; boolean
flags are assertions from the trusted calling boundary, not independently checked
by this module. A second publisher estimate is not automatically proof of a CBA
charge. This is a narrow integration step, not complete team cap accounting.

Remaining: production itemized acquisition with approved access; source evidence
verification beyond caller assertions; full non-roster/retention/buyout/bonus
classification, daily accounting, LTIR relief and all-domain completeness; Scout
response integration and real Toronto end-to-end acceptance.

Validation: `Tests/validate_contract_evidence_verification_0710300.py` plus
existing acquisition, CBA, Cap Freeze and release hygiene validators.
