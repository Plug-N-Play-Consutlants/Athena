# v0.7.10.25.0 — Contract Obligation Acquisition

This release adds an authorized, itemized contract-obligation acquisition adapter. It uses the existing HTTPS snapshot acquisition boundary and canonical ingestion. Verified active-roster SPC AAV may become a standard contract charge; nonstandard obligations must carry an independently CBA-verified cap charge and rule reference. Invalid teams, unknown obligation classes, unverified statuses, and negative amounts are rejected.

**Scope limit:** No production NHL contract-data provider has been configured or verified. This is a bounded ingestion/normalization capability, not a live NHL salary-cap result. AAV is not a universal substitute for cap accounting; especially LTIR, daily accrual, buried salary, retained salary and bonuses remain outside this transformation. The adapter deliberately downgrades any input to partial coverage. It never certifies a complete ledger based solely on feed claims.

**Next release blocker:** identify and integrate an authorized real-world itemized NHL contract/roster provider, map its actual schema, acquire independent adjustment evidence, apply effective-dated CBA rules, and reconcile real team results before asserting operational cap accuracy.

**Local checks:** `Tests/validate_contract_obligation_acquisition_0710250.py`, existing cap acquisition/ingestion/ledger regressions, and `Tests/validate_release_hygiene.py`. Studio acceptance remains user-operated.
