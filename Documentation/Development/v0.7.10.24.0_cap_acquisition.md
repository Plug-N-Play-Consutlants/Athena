# v0.7.10.24.0: Authorized cap snapshot acquisition

This patch adds a bounded acquisition boundary for **authorized publishers of the canonical snapshot schema**, not a live vendor adapter. It does not claim PuckPedia, NHL, or any other external provider supplies this schema or an unrestricted API.

`Knowledge/Contracts/cap_snapshot_acquisition.py` validates explicit authorization and HTTPS, blocks redirects and non-public literal IP/localhost endpoints, bounds response size, and requires requested team/date identity. It then delegates to `ingest_cap_snapshot`, preserving explicit provenance and coverage claims. Offline tests inject a transport and do not establish live availability. A deployment must additionally enforce network egress allowlisting and DNS resolution protections if source configuration is untrusted.

Remaining release-critical work: evaluate lawful/licensed real provider interfaces; implement raw-contract and roster adapters; verify full team contract coverage; derive CBA-governed obligations, LTIR and other adjustments; reconcile against published totals; connect live acquisition and calculations into Scout. This release **must not** be described as live NHL cap coverage or complete CBA accounting.
